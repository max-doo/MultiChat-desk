## 二、 编辑级 SVG 制图规范 (消除“粗糙 PPT/Visio 感”)

HTML 正文遵循“零卡片纪律”，SVG 内部必须贯彻同一套美学逻辑：

### 1. 延伸“零卡片纪律”至 SVG 内部
* **分层架构 / 流程模块**：优先使用**无描边极浅色带（`fill="var(--band)"` 或同色系浅 5–8% 底色）+ 左侧 `4px` 彩色定位竖线**；右侧辅助批注用**开放式括号竖线 / 虚线分隔线 + 纯文字**，彻底告别四边全封闭彩色描边盒子。
* **严禁 SVG 实心黑砖块**：在亮色页面中，禁止用大面积纯黑/炭黑填充矩形（如 `fill="#0F172A"`）来表示“核心层/最终阶段”。高亮节点请改用：
  - 主色实心圆点 + 虚线外环（用于轨迹图/时间轴）；
  - 同色系稍深 4% 的柔和底色 + 辅色左定位线（用于分层图）；
  - 简洁的辅色标签文字（`--accent-2-text`）。

### 2. 物理比例尺规范（防止字体傻大与线条粗笨）
* 全宽 SVG（横跨 12 列内容区，约 `1150–1220px`）的 `viewBox` 宽度推荐设为 **`860–960`**（高度视内容复杂度取 `260–420`）。
  - 原因：若 `viewBox` 宽度仅 `700–720`，在桌面端会被放大 `1.7×`，原本 `12px` 的标签渲染成 `20px+` 巨字，`1.6px` 的线条变粗成 `2.8px`，精致度瞬间崩塌。
  - 当 `viewBox` 宽度在 `880–920` 时，放大倍率仅 `1.25–1.35×`，代码中的 `12–13px` 文字渲染为清爽的 `15–17px`，`1–1.5px` 网格线保持发丝质感。
* SVG 内部字号遵循层级：主标签 `13–14px`（加粗）、次级说明 `12–12.5px`、坐标轴刻度 `11.5–12px`（等宽体，严禁低于 `11px`）。

### 3. 数据图表的单色系语义编码
* **同类柱条统一使用单一主色（`--accent`）**，严禁 4 根柱子用 4 种互不相关的深色（彩虹柱状图）。
* **多口径/区间数据采用“套柱”或“主色+浅色延伸段”**：例如已核实下限/净值用实色主条，行业估算上限/范围区间用同色系 35–45% 明度浅条紧接其后，既省空间又信息丰满。
* **单点高亮规则**：只有当某一项代表“关键转折、软件新范式、异常风险”时，才将其单独切换为辅色（`--accent-2`），且全图高亮项不超过 1–2 处。
* **避坑提醒（防折线压字与极端尺差）**：
  - 折线图/路径图的数据标签必须给足垂直偏置（至少距折线和圆点 `>= 14px`），并避开斜线穿过路径。
  - 若某组柱状图存在量级相差 30 倍以上的极端值（如 `54 亿` vs `1.6 亿`），避免硬塞在同一线性横轴里导致小值缩成几乎看不见的细条，可改为文字附注或独立指标条带（`.kpi-row`）。

### 4. 图表三层信息结构（`<figure>` 标准解剖）
```html
<figure>
  <div class="fig-head">
    <div class="fig-title">图 1：带动词的完整结论句标题</div>
    <div class="fig-sub">一句话导读副标题：说明纵横轴含义、统计口径或读图视角</div>
  </div>
  <svg viewBox="0 0 900 320" width="100%" role="img" aria-label="图表语义描述">
    ...
  </svg>
  <figcaption>注：单位与权威数据来源说明（12–12.5px 柔灰收尾，不加顶部横线）。</figcaption>
</figure>
```
