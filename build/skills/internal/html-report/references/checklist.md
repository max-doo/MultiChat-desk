# 发布前 10 项逐条自检清单 (Pre-flight Checklist)

在交付或发布可视化 HTML 报告前，必须逐项核对并确保全部达标：

1. **[全局字号与真实 WCAG 对比度]**：
   - 全局文本、表格表头、图注、SVG 坐标轴刻度及标签字号 `>= 11px`（正文推荐 `15–16px`）。
   - 主画布（`--paper`）上所有文本对比度严格 `>= 7:1`（WCAG AAA）；过渡带（`--band`）上文本对比度 `>= 6.5:1`。
   - 页面包裹在 `max-width: 1360px–1440px` 居中容器内；正文行宽控制在 `max-width: 68–72ch`。
2. **[中文排版性格与防断词]**：
   - 中文报告已配置合理的字体性格映射（研究/期刊/人文优先 `Noto Serif SC` 标题 + `Noto Sans SC` 正文 + 等宽数据），不依赖纯拉丁字体充当中文标题。
   - `<h1>` 与 `<h2>` 显式声明 `text-wrap: balance;`。
   - 表格数值列使用 `.num`、2–6 字短主键列使用 `.lead`（`white-space: nowrap`），严禁类别词被劈成“3+1”两行。
3. **[色彩克制与零突兀重色]**：
   - 遵循 85% 中性面 + 10% 主强调色 + 5% 语义辅色配比，页面具备 `--paper` 与 `--band` 两阶浅底过渡。
   - 亮色长文报告中，高潮通栏默认采用同色系轻着色带（`.pull-band`）；全篇通栏带上限 1 处（`.band-dark` 仅限 `Expressive` 强表现力题材或用户明确要求）。
   - **SVG 内部零“纯黑砖块”**：亮色画布的 SVG 中严禁出现大面积 `#0F172A` / `#000000` 实心矩形块来高亮重点。
4. **[全域零卡片与去冗余边框]**：
   - HTML 零卡片盒子；**SVG 结构图同样拒绝四边封闭彩色描边盒子堆砌**，优先用无描边浅色带 + 单边定位色条、开放式引导线与轨迹线。
   - 同一边界只画一根线：禁止 `.verdict-strip` 与子项叠加双横线，禁止给所有 `h2` 硬加粗黑顶线，`<figcaption>` 顶部不加冗余横线。
5. **[观点化标题与有效语义导引]**：
   - 所有 `<h2>` 均为传递观点的完整陈述句，无模板空标题（“引言/概述/总结”等），无 `<h2>` 内机械数字前缀。
   - 严禁无信息量的伪刊头或装饰性英文标签（如 `PAGE 01`、`DATA REPORT`）；允许有真实信息量的轻量中文定位眉题（`.kicker` / `.sec-kicker`）与读图副标题（`.fig-sub`）。
6. **[版式交替节奏与正表互补]**：
   - 相邻两节严禁重复相同布局，在左右分栏、多列 `.pillar`、`.kpi-row`、全宽图表、三线表与通栏之间交替推进。
   - **正表互补不重复**：避免正文大段逐条展开全部案例后，紧接着又用表格把同一批案例原样复述一遍；同类多行表格优先用 `rowspan` 合并首列去重。
7. **[编辑级 SVG 比例尺与零碰撞]**：
   - 全宽 SVG `viewBox` 宽度控制在 `860–960`（避免 `< 760` 导致桌面端放大失真、文字傻大笨重）。
   - 同类柱状图/数据序列采用**单色系编码**（浅色延伸段表区间，辅色仅点亮异动/拐点项），严禁“一柱一色”。
   - 全部文字与图形落在 `viewBox` 内，无裁切、无文字重叠、无折线穿字，无 `//` 分隔符；每个 `<figure>` 具备 `.fig-title` + `.fig-sub` + `<figcaption>` 三层完整结构。
8. **[配图与图形一致性]**：
   - 若使用位图/插图，全篇统一圆角半径（通常 `0px`，消费杂志可统一 `24px`）；概念插图采用与画布同色的无缝底，不加拟物阴影。
9. **[事实追溯与结论可信度]**：
   - 数据加总与口径自洽，外部客观事实提供内联链接或文献标注，文末配有双栏结构化参考来源列表（`.sources-list`）。
10. **[纯静态校验与可选渲染审计]**：
    - 零 `<script>`、零内联事件、零交互表单标签；除 Google Fonts 外零外部资源引用；所有本地图片已 Base64 内联。
    - 运行 `python scripts/build_report.py <report.html> --visual-audit` 输出 `PASSED` 且无渲染级碰撞告警。
