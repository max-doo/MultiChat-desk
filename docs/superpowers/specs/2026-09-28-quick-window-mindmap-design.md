# 快捷窗口新增思维导图（幕布）功能设计方案

## 1. 背景与目标
MultiChat 桌面端快捷窗口（Quick Window / Float Window）当前支持主 AI 模型的快速交互，并配备可伸缩侧边栏支持多模型对照（副模型）与划词提问。
为了满足重度用户的结构化梳理和思维导图记录需求，需在快捷窗口右上角工具栏中新增“思维导图”入口按钮，点击后复用现有侧边栏容器，在 Webview 中加载 [幕布](https://mubu.com/app)（`https://mubu.com/app`）。

## 2. 交互逻辑与状态设计

### 2.1 顶部操作栏布局
在快捷窗口主 Webview 头部操作区（`WebviewCard` 的 `headerActions`）：
位置：在“主界面”按钮与现有“侧边栏切换按钮”之间（或紧邻侧边栏切换按钮）。
- 按钮图标：Material Symbols `account_tree`（思维导图树状分支图标）。
- 提示文案（title/aria-label）：`思维导图`。
- 状态呈现：当侧边栏展开且当前展示内容为思维导图时，按钮高亮（主题色背景/文字，与现有激活按钮样式一致）。

### 2.2 侧边栏双模式复用机制
现有侧边栏容器（拖拽调宽、展开/收起宽度动画与 IPC 同步）完全复用，增加模式状态 `sidebarMode: 'model' | 'mindmap'`：

1. **思维导图按钮点击行为**：
   - 若侧边栏已关闭：展开侧边栏，将模式设为 `'mindmap'`，加载/唤醒幕布 Webview。
   - 若侧边栏已打开且当前为 `'mindmap'`：收起侧边栏，并触发侧边栏 30 秒休眠倒计时。
   - 若侧边栏已打开且当前为 `'model'`：保持侧边栏展开状态，模式切换为 `'mindmap'`，同时副模型启动 30 秒休眠倒计时。

2. **原有侧边栏按钮（AI 对照）点击行为**：
   - 若侧边栏已关闭：展开侧边栏，将模式设为 `'model'`，展示/唤醒副模型 Webview。
   - 若侧边栏已打开且当前为 `'model'`：收起侧边栏，并触发副模型 30 秒休眠倒计时。
   - 若侧边栏已打开且当前为 `'mindmap'`：保持侧边栏展开状态，模式切换为 `'model'`，同时思维导图启动 30 秒休眠倒计时。

3. **划词发送到侧边栏（`onQuickAskSidebar`）行为**：
   - 触发划词发送至侧边栏提问时，自动将模式切换为 `'model'` 并展开侧边栏，确保文本正确注入到 AI 模型的输入框中。

## 3. Webview 与页面容器设计

### 3.1 幕布 Webview 实例
- 使用 `WebviewCard` 组件（设置 `hideHeader: true`），具备完整的 `WebviewCardRef`（支持 `suspend()` 与 `resume()`）。
- URL：固定为 `https://mubu.com/app`。
- Session：共享 `persist:shared`，保持用户在幕布的登录凭证及 Cookie。
- 实例 ID：`quick-sidebar-mindmap`。

### 3.2 专属头部控制栏
由于幕布不是普通大模型，不使用通用模型的下拉切换选择器，采用专属头部导航条：
- 左侧：思维导图图标 + “思维导图 (幕布)” 标题。
- 右侧功能按钮：
  - 刷新按钮（`refresh`）：调用 webview reload。
  - 收起按钮（`close`）：关闭侧边栏（同时触发 30 秒休眠倒计时）。

### 3.3 侧边栏统一休眠与销毁策略（30 秒规则）
侧边栏的所有内容（包括副模型和思维导图）统一采用 30 秒休眠/销毁规则，释放页面层内存：
1. **休眠触发时机**：
   - 侧边栏关闭时，对当前展示的实体（模型或思维导图）启动 30 秒倒计时；
   - 快捷窗口隐藏（`onQuickHidden`）时，若侧边栏原本展开，对当前实体启动 30 秒倒计时；
   - 侧边栏从 A（如思维导图）切换到 B（如副模型），或者副模型之间互相切换时，对被切走的实体启动 30 秒倒计时。
2. **休眠执行机制**：
   - 倒计时到期后，若侧边栏未处于展开且显示该实体的状态，调用其 `ref.suspend()`，页面导航至 `about:blank` 释放 Chromium 渲染层 V8 堆和 DOM 树。
3. **唤醒机制**：
   - 当用户再次打开侧边栏或切换回该实体时，清除该实体的休眠定时器；若实体已处于休眠状态，立即调用 `ref.resume()` 重新加载 URL。

## 4. 影响范围与验证方案
- **涉及修改的文件**：`src/renderer/src/pages/QuickPage.tsx`。
- **无需修改的文件**：主进程与 preload。
- **验证步骤**：
  1. 执行 `npm run lint` 检查代码规范与 TypeScript 类型；
  2. 执行 `npm run build` 确保前端构建无报错；
  3. `npm run dev` 调起快捷窗口，验证：
     - 点击思维导图按钮能否正确展开侧边栏并加载幕布；
     - 关闭侧边栏或在思维导图与副模型之间切换后，等待 30 秒，确认对应页面触发 suspend 休眠；
     - 再次打开侧边栏时，确认页面自动 resume 唤醒并恢复访问；
     - 切换思维导图与副模型时，侧边栏内容正常切换，调宽手柄正常，关闭按钮正常。
