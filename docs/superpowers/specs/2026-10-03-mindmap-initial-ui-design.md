# 思维导图初始界面 UI 重构与交互设计方案

## 1. 现状剖析与改动依据

### 事实（Fact）
1. 当前思维导图侧边栏具有两层顶部栏结构：
   - 第一层（`MindmapSidebarView`）：包含思维导图图标、[本地 | 在线] 分段切换 Tab 与关闭按钮。
   - 第二层（`ConversationMindmapPanel`，即用户截图标注的红框）：包含重复的“思维导图”文本与“更多 ∨”下拉菜单。
2. 在初始无导图状态下，“选择模型”、“按要求生成（额外要求）”、“新建空白导图（手动创建）”均被折叠在“更多 ∨”下拉菜单内。
3. 主界面中央仅有一个单独的“生成导图”按钮和文字说明。

### 证据（Evidence）
- 代码源自 `src/renderer/src/components/ConversationMindmapPanel.tsx` 第 365~372 行：
  ```tsx
  <div className="px-3 py-2 border-b border-gray-100 flex items-center justify-between gap-2">
    <span className="text-sm font-medium text-gray-700">思维导图</span>
    {controls}
  </div>
  ...
  <div className="flex-1 min-h-0 flex flex-col items-center justify-center gap-3 px-6 text-center">
    ...
    {generateButton}
    <p className="text-xs text-gray-400">使用 {platformName} · 自动保存到笔记</p>
  </div>
  ```
- 侧边栏外层已有 `MindmapSidebarView.tsx` 第 50~118 行的顶栏。

### 推断（Inference）
- 现有红框子顶栏在视觉与层级上存在冗余；
- 核心参数与入口被隐藏在下拉菜单中，导致“模型选择”、“额外要求”与“手动创建”的发现性较差，用户需要两次点击才能完成配置。

### 观点与客观评估（Opinion & Risk Evaluation）
- **认同点**：完全赞成删除初始界面的红框子顶栏（“思维导图”与“更多 ∨”），这能释放约 40px 的纵向空间并消除视觉重复。
- **潜在盲点与风险提示**：
  1. 用户提出的 4 个元素属性并不相同：
     - “模型选择”是**选择型控件（Selector）**，需要常态展示 Logo 和名称，点击展开选择；
     - “额外要求”是**配置输入项**，需要提供输入承载载体（内联展开折叠或轻弹窗）；
     - “生成导图”是**主行动（Primary Action）**；
     - “手动创建”是**次级行动（Secondary Action）**。
  2. 若简单地将它们硬编码为平铺并列的 4 个相同按钮，在侧边栏通常只有 320px~420px 宽度的情况下，横排必定拥挤折行，视觉层级混乱。因此必须按照“参数配置”与“触发行动”分层设计。

---

## 2. 方案对比与设计细节

### 方案 A：聚焦配置控制台（强烈推荐 / Recommended）
将中央空态区改造为一体化的“生成控制台”，自上而下形成流畅的视觉动线：

1. **顶部区域**：
   - 彻底移除红框，顶栏直接紧接 `MindmapSidebarView`；
   - 任务状态与错误提示通栏吸顶（若有）。
2. **中央引导区**：
   - 柔和浅色背景的导图图标（`hub` 或 `account_tree`）；
   - 主标题：“把当前对话整理成思维导图”；
   - 副标题：“提炼对话脉络，或自由编辑空白画布”。
3. **参数配置卡片（紧凑浅灰底容器）**：
   - **模型选择器（带 Logo）**：
     - 常态显示：彩色平台 Logo（ChatGPT / Claude / DeepSeek 等，从 `models` 读取）+ 平台名称 + 下拉指示箭头 `expand_more`；
     - 交互：点击展开下拉浮层（支持已启用模型列表过滤，高亮当前选中项）。
   - **额外要求折叠栏**：
     - 常态显示：图标 `tune` + “额外要求” + 状态徽标（已输入时显示“已设”蓝标）+ 展开箭头；
     - 交互：点击内联滑出平滑的多行文本框与快捷确定/清空按钮（无需全屏弹窗打断心流）。
4. **行动按钮区（主次分明）**：
   - 主按钮：**[ ✨ 生成导图 ]**（全宽，主题蓝底高对比度，带加载状态，视觉绝对重心）；
   - 次按钮：**[ ✏️ 手动创建空白导图 ]**（全宽，白色背景描边，轻量辅助，满足纯手工绘图需求）。
5. **底部说明**：
   - 遵照用户确认，完全删除底部的“自动保存到笔记 / 使用模型”等次要提示文案，让界面保持极致清爽干净。

---

### 方案 B：双通道分流卡片
将“AI 智能生成”与“空白自由绘制”彻底解耦为两个平行的功能通道：

1. **AI 智能提炼卡片**：
   - 顶部标有“AI 智能提取”与“推荐”标签；
   - 内置 2 列网格：左侧为 [模型选择（带 Logo）]，右侧为 [额外要求（点击弹窗）]；
   - 底部全宽按钮：[ 一键生成导图 ]。
2. **手动绘制通道卡片**：
   - 标题：“空白画布自由绘制”；
   - 说明：“从空白节点开始，快捷键轻松添加同级、子级节点”；
   - 按钮：[ 创建空白导图 ]。

---

### 方案 C：极简底部紧凑动作组
保留中间大面积留白与大图标，所有操作收缩到底部动作区：
- 第一行：[ 模型选择（Logo+名称 ∨）] (占 60% 宽度) + [ 额外要求 ✎ ] (占 40% 宽度)；
- 第二行：[ 生成导图 (主) ] (占 50%) + [ 手动创建 (次) ] (占 50%)。

---

## 3. 方案对比矩阵

| 评估维度 | 方案 A（聚焦控制台 - 推荐） | 方案 B（双通道分流） | 方案 C（极简动作组） |
| :--- | :--- | :--- | :--- |
| **窄侧边栏适配度** | 优秀（垂直流式，永不截断） | 良好（卡片较多需滚屏） | 一般（水平按钮多易拥挤） |
| **模型 Logo 展示效果** | 专属下拉条，Logo 与名称完整清晰 | 紧凑小卡片，清晰度良好 | 压缩在半宽内，长名称可能截断 |
| **额外要求易用性** | 内联折叠展开，免弹窗，带已设徽标 | 点击弹出 Modal 模态框 | 点击弹出 Modal 模态框 |
| **主次层级清晰度** | 极佳（生成主按钮，手动次按钮） | 极佳（两个独立卡片） | 一般（并列两按钮权重趋同） |

---

## 4. 建议与下一步行动

### 建议（Recommendation）
优先采纳 **方案 A**。其优势在于：
1. 完全消除了冗余标题，界面呼吸感好；
2. 模型选择带彩色 Logo，且保留了未来支持搜索或展示更多模型的能力；
3. 额外要求内联展开，体验丝滑；
4. 主次按钮上下垂直排列，既能最大程度适应 300px~450px 的侧边栏伸缩宽度，又能清晰引导用户优先使用 AI 一键生成，同时满足手动建图诉求。
