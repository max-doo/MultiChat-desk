本次针对性调整重点

1
.gitignore 编辑区直接可见，不设折叠

代码区域直接位于预设下方，所见即所得。编辑区保留紧凑合理的 9 行高度并支持纵向拉伸，不再增加“展开/收起”的点击层级。

2
移除所有假定状态的小绿点与 Git 标签

彻底拿掉了标题处的 Git 徽标以及输入框旁的拟态指示灯，不做任何多余的装饰，杜绝不准确的连接状态假定。

3
预设提供“胶囊标签”与“规整多选”两种直观对照

在左上角提供一键切换：既可以查看更轻盈的“胶囊标签”（3行搞定），也可以查看对齐严整的“规整多选”布局，两者均与下方编辑器实时双向同步。

即时互动测试

  • 双向实时联动：点击任意预设，下方代码区域与行数自动增删；直接在代码区输入新行或删除旧行，上方预设勾选状态自适应刷新。
  • 方案 A vs 方案 B：点击顶部可在“双标签分流（无滚动条）”与“单页流式卡片”间切换。
  • 大文件一键加入忽略：点击大文件告警的“+ 忽略 *.tar.gz”，规则秒级注入文本框并消除警报。
  • 数据迁移状态跑通：切换至“存储与维护”标签，点击“开始迁移”可直观预览进度条流转。
