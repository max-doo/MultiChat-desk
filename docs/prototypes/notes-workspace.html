一份资料，两种思考方式

设计选择

以来源对话为资料单位，批注和思维导图共享标题、原文与来源。每张会话卡片直接展示引用和评论，支持就地补充想法；右栏只解释当前选中内容的上下文。默认以瀑布流展示全部会话的批注与想法。点击卡片的思维导图入口后，同一工作区改变布局：笔记收窄为左侧栏，导图在中间展开，右侧保持原会话对照。关闭导图恢复首页及浏览位置。点击批注或导图节点，右栏直接展开原会话并定位；中间的笔记或导图保持可见，可同时对照。右栏优先使用原始网页，本地快照为可选来源。

问题新交互
最新笔记不在顶部默认按最近更新时间降序；新增批注、编辑评论或保存导图后，所属资料更新排序时间；正在编辑时保持卡片位置，重新排序或重新打开后按最新顺序展示。创建时间排序作为明确的备选。
多处重复展示批注首页每个会话一张卡片，直接展示批注与想法；进入导图时同一笔记区域收窄为侧栏，避免重复列表。
原文高亮缺失已有引用持续高亮；选中批注后滚动到来源，原文高亮也可反向选中批注。定位失败时保留引用和评论，并明确提供重新关联入口。
导图被侧栏和工具挤压点击会话卡片的导图入口，在同一页面展开画布；拖动平移、滚轮缩放、适配视图。点击节点直接在右栏显示来源，不替换导图。双击节点可就地编辑。
快照、网页与导图同级首页集中展示全部笔记，点击卡片内的导图入口展开中间画布；原始网页和本地快照在右侧来源菜单中切换。

调研依据

Readwise Reader · 高亮与批注：阅读中的高亮、评论以及侧栏交互。借鉴引用与阅读上下文的连接。阅读导航提供侧栏折叠和明确的排序依据。

Xmind · 导图与大纲：同一内容的结构视图与线性视图切换，并提供缩放与编辑。借鉴导图 / 大纲切换，不把大纲混入批注筛选。

Obsidian · Canvas：空间中的资料关系、编辑和连接。借鉴内容和来源相连的思路；本原型继续保留项目现有的树形思维导图。

推荐体验路径

  1. 点击任意黄色引用或“查看原文”，右栏自动展开原会话并定位。点击原会话中的黄色高亮，回到对应批注。
  2. 编辑一条评论，再搜索评论中的词；资料搜索覆盖标题、引用、评论与导图文字。
  3. 点击卡片底部的“思维导图”，笔记收窄为左侧栏；点击“消费健康与医疗器械的分界”，查看节点来源；再切换大纲、缩放、拖动画布。
  4. 在右侧原会话中选择文字，点击“保存批注”。需要离线阅读时，在右栏来源下拉菜单选择本地快照。
  5. 点击下方演示按钮，体验新增资料、定位失败与导图为空的状态。

快捷键与边界

Ctrl K 搜索，Alt 1 笔记，Alt 2 思维导图，Alt 3 来源侧栏，Esc 关闭弹窗。桌面可拖动来源侧栏左边缘调整宽度；窄窗口使用上下分区，保留笔记、导图与来源的阅读关系。

这是离线可运行的交互原型。搜索、排序、编辑、高亮、大纲、缩放、重新关联、删除撤销和 Markdown / JSON 导出可真实操作。右栏原始网页使用独立的离线会话示例；“调整导图”生成固定演示候选，供体验确认流程。原型没有连接真实 AI 平台或应用数据。
