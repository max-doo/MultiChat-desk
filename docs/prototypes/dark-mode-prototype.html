1. 顶部纯暗底 + 底部晴蓝融粉渐变

窗口顶部（含标题栏与窗口控制按钮区）完全保留纯净深炭灰 #101115，避免任何额外色光干扰；所有渐变仅从底部向上缓缓透出，并通过多停靠点横向连续过渡让 晴蓝与微粉自然熔合为一整条流畅的呼吸地平线。

上层 6 段椭圆渐隐罩叠在微斜的横向蓝粉渐变之上，彻底消除了分体光斑的生硬边界。

2. 统一 CSS 变量示例

/* index.css · 顶部纯底色 + 底部无缝融合蓝粉渐变 */ .dark { --app-bg: radial-gradient(142% 62% at 50% 106%, transparent 0%, rgba(16,17,21,0.38) 42%, #101115 90%), linear-gradient(96deg, #1B4B9C 0%, #245CB3 24%, #335A9E 46%, #4E4974 66%, #753E54 100%); --glass-bg: rgba(24, 24, 27, 0.54); --surface-solid: #18181B; }
