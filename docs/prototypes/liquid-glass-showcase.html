Electron 下为什么不能盲目堆叠大面积 backdrop-filter？

当弹窗或下拉菜单跨越底层 <webview>、长文档滚动容器以及玻璃侧栏时，大半径的 backdrop-filter: blur(24px) 会迫使 Chromium 合成器在每一帧对下层像素做离屏拷贝与高斯卷积。视觉上哪怕只差几毫秒，在低功耗本或连续拖拽分隔条时都会表现为掉帧。

// 仿液态玻璃（零模糊合成）关键在于：高光边缘 + 方向性光泽 + 适度微透
background: linear-gradient(160deg, rgba(255,255,255,0.93), rgba(247,250,255,0.87));
box-shadow: inset 0 1.5px 0 rgba(255,255,255,0.98), 0 20px 44px -12px rgba(15,23,42,0.16);

全屏遮罩 blur高（全屏逐帧采样）差（易卡顿）需额外压暗层
