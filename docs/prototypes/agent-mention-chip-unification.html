方案对比

维度① 轻图标+白文（推荐）② 弱图标+淡文③ 下划线④ 中字重
突兀感 低：无背景，仅前置小图标最低：几乎融入正文中下：下划线增加视觉元素低：无背景仅字重变化
"这是文件"的辨识度 图标 + 文件名组合可辨弱，可能被当作普通文本最强，链接语义直白中等，字重差异较微妙
与既有行内 chip 的统一性 同透明底、同几何、同 hover 浮现逻辑，仅文字色随气泡反白同左多了下划线这一独有元素多了字重这一独有元素
文件类型图标语义 白色剪影保留形状（md/ts/pdf/文件夹可辨），失去色彩同左且更弱同①同①
实现成本 删背景类 + 调透明度同左加下划线样式与 hover 加深加 font-medium
推荐 ① 的理由：蓝气泡上彩色图标不可行（红 PDF、蓝 TS 压在品牌蓝上杂乱），白色剪影图标在 72% 透明度下既能暗示"文件类型"又不抢戏；文件名保持与正文同纯白， chip 读起来就是句子的自然组成部分，只有前置小图标和 hover 微光提示它可点击。若觉得"可点"信号还不够，③ 的下划线是最直白的加强版；若嫌下划线多余，④ 用字重压中。

共同的统一点：四个方案都已对齐行内 chip 的核心 —— 透明常态底、hover 才浮现底色、gap 4px、内边距 2·4px、字号继承正文 14px、文件名 208px 截断。差异只在气泡反白环境下的文字/图标处理。
