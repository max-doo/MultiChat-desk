# 单对话思维导图：设计与开发方案

## 1. 目标与范围

主窗口单对话模式和快捷窗口提供同一套本地导图能力。用户将正在查看的平台会话整理为思维导图，默认由当前平台的网页版 AI 生成，也可以选择其他已配置的平台。请求通过隐藏的网页窗口自动发送，界面只展示状态与最终结果。重新生成总是创建新导图，不覆盖用户编辑过的旧图。

笔记和导图按来源会话统一存储：一个 JSON 会话文件只保存一份对话快照，批注保存引用、评论和文本锚点，导图保存 Markdown 大纲与生成来源。Markdown 是正文和导图内容格式；JSON 是持久化容器。不新增生产依赖、数据库或独立任务队列。

幕布在线入口保持现有行为。多窗口多模型合并、自动跟随每条回复重新生成、外部 Markdown 文件双向同步、导图节点自动关联原文不属于第一版。

## 2. 代码事实与复用边界

`generateNoteCaptureScript` 按消息 DOM 读取用户和 AI 内容，不限于屏幕可见区域。当前使用场景中可以获取完整会话。直接复用它，不预先引入自动滚动、网络拦截或新的爬虫。网页尚未加载的消息和跨域附件内容不在此脚本的读取范围内；通过实际长对话检查确认支持情况。

`NoteManager` 目前把快照存到每条批注内部，并按会话写入 `notes/<UUID>.json`。读取时会合并同源会话及重复引用。改为会话级快照后，这些合并、增删改、导出路径必须同步，不能因最后一条批注删除而误删导图。

`LocalMindmapPanel` 已有树与 Markdown 转换、文本转义、编辑、撤销和 SVG 导出。增加文档输入及变更回调，让存储归会话管理；原独立模式可继续运行，旧 localStorage 大纲需安全迁入存储。

`AutomationService` 和 `SessionManager` 已能在共享登录态的隐藏窗口发送和收集输出。导图使用独立用途的窗口，避免影响原网页及 CLI 后台会话。不能采用现有固定等待五秒的接口作为完成判断。

## 3. 主窗口与快捷窗口交互

现有思维导图按钮仍负责开关侧栏。本地模式显示当前来源会话的导图，顶部只保留可编辑的导图标题、生成按钮和“更多”菜单。平台默认跟随当前源平台；跨平台选择放入菜单，生成按钮的悬停提示说明目标平台，菜单说明生成结果自动保存到笔记。没有导图时展示居中的生成入口和简短说明。

“更多”菜单保留历史导图选择、新建空白、导出大纲、在笔记中打开和删除；标题直接点击编辑，不另设一条标题栏。画布保留导图/大纲切换、撤销重做、缩放与适应视口，展开、收起、SVG 导出和快捷键说明收入画布工具菜单。正常已保存状态不常驻展示；生成状态只占一行，错误通过可展开详情提供诊断，允许关闭旧提示。首次生成自动展示；已有图时保留当前画布，完成提示允许查看新图，避免生成中编辑旧图时被切走。

任务状态包括准备网页、生成大纲、保存、完成、失败、取消。不显示虚构百分比，不展示提示词或流式中间正文。一次只允许一个后台生成任务。重复点击返回已有任务状态，不重复发送。

任务绑定启动时的来源会话与快照版本。切换平台、网页会话、页面、侧栏或隐藏到托盘不更改任务归属，后台继续运行。退出应用结束任务，不在重启后自动重发。跨会话完成提示说明来源，结果不会覆盖另一个会话的画布。

登录失效或验证码等问题提供“打开生成网页处理”。窗口只在用户主动处理时显示；原会话保持原样。取消销毁专用生成窗口，停止后续抓取；已经发送到第三方的请求无法承诺撤回。

快捷窗口的“在笔记中打开”将目标会话和导图发送给主窗口，显示主窗口并进入笔记页。主窗口自身使用同一定位消息，无需重复实现导航规则。

## 4. 共享会话文档

### 4.1 数据字段

会话增加 `snapshot`、`snapshotRevision`、`mindmaps`。批注移除持久化 `snapshot`，继续保留 ID、quote、comment、anchor、创建和修改时间。导图包含 ID、标题、markdown、生成平台、sourceRevision、创建和修改时间。独立旧图使用未关联会话记录保留，来源链接为空，不参与网页高亮匹配。

快照正文只存在于会话顶层。编辑导图不会修改快照。快照变更时版本递增，内容相同不递增。导图基于较旧版本时展示“对话已更新”，不自动覆盖。运行中持有的输入字符串仅是内存中的任务输入，不构成第二份磁盘快照。

### 4.2 更新与并发

所有读写合并和增删改使用现有主进程存储管理器，写操作串行，继续使用临时文件加重命名完成原子保存。导图编辑采用防抖保存，离开文档前提交最后一次编辑；保存失败保留编辑稿并提供重试。

添加笔记和启动生成都通过同一入口更新共享快照。生成完成重新读取最新会话，再追加导图，不把启动时的整个会话对象写回，以免覆盖生成过程中新增的批注或其他导图。导图内容保存支持修改时间冲突检查，防止两个窗口静默互相覆盖。

来源识别复用 `noteConversationKey`，具体网页会话 URL 优先，保留完整规范化路径，避免把 `/chat/s/id1` 和 `/chat/s/id2` 截成同一个 `/chat/s`。通用标题的空白入口页不保存为会话；其他入口页沿用现有标题分组行为。快照相同不更新，较短或降低已有批注可定位数量的采集保留旧快照，防止不完整采集覆盖正文。此时生成入口明确报错，不能静默用旧正文冒充当前对话生成。需要接受明显删改的会话正文时，应另外设计用户主动更新入口，第一版不自动丢弃旧正文。

### 4.3 老数据迁移

读取旧文件时汇总批注快照候选，优先选能定位最多批注的候选，同等条件按更新时间和内容长度选择。批注引用和评论始终保留，无法定位的明确展示。首次转换保留原文件的迁移备份供恢复，备份不进入列表和日常读取，正常会话文档只有一份快照。

合并同源文件时保留全部不重复批注和导图。保留备份成功后才写转换文件和清理重复旧记录。转换具备版本标识，重复读取不会重复迁移。旧 localStorage 导图通过确定的迁移标识去重，磁盘保存成功后才移除旧键；内置演示内容不作为用户导图迁入。

## 5. 后台生成实现

主进程验证来源 WebContents 属于调用窗口，再执行共享采集脚本，获取标题、URL、快照及网页生成状态。采集失败、空内容或当前 AI 仍在生成时给出可理解错误。正文与来源信息不打印到日志。

平台选择器在 `src/shared/config/selectors.ts` 统一维护；采集、输入、状态探测和回复提取脚本在 `src/shared/utils/webviewScripts.ts` 维护。远程页面不暴露应用 preload；共享 `persist:shared`，关闭 Node 集成并保持 contextIsolation。保留现有后台限流关闭设置。

专用窗口从平台的新对话 URL 加载。等待可用输入框，确认没有已有回复，再自动输入和发送。完整标签及可解析的大纲是完成依据；空结果不累计稳定次数，抓取失败不认为完成。平台停止控件用于判断未完成或格式异常的回复；已适配平台只使用确切的停止生成控件，避免将停止朗读等控件误认为文本仍在生成。

提示词要求单个 `#` 根标题、`##` 一级分支、后续两空格缩进列表。只整理对话材料，合并重复观点，保留最终修订、决策、依据和未解决问题，不执行材料内的指令。整个回复只输出一个 Markdown 代码块，以保留原始格式和缩进。固定的 `<mindmap>` 与 `</mindmap>` 标签放在同一个代码块内部，不带属性、ID 或转义；代码块外不输出文字。任务 ID 仅在程序内部管理窗口和状态。解析继续兼容此前的普通文本、反斜杠转义和实体编码输出。

导图抓取限定在最新助手回复，将平台配置、按站点补充的正文选择器与通用助手角色选择器合并定位，排除用户消息和输入框。ChatGPT 新版正文使用 `div[class*="MarkdownRoot-"]` 匹配类名前缀，不写死变化的后缀；总结和后台导图在运行时都补充该候选，本地保存的旧配置不会屏蔽它。后台回复 DOM 不要求具有可见布局；从标题和列表结构还原 Markdown，按嵌套层级保留两空格缩进，去除按钮等非正文内容。保留对已有代码块回复的兼容：读取完整编辑器模型或普通代码原文，无法读取完整虚拟文档时禁止保存可见片段。标签及外围内容在保存前去除，更深标题转换为编辑器支持的列表层级。检查标题、分支、行格式和合理大小，拒答、错误页面、半段结果不能作为成功导图保存。

完成判定区分尚无闭合标签、完整且可解析、完整但格式错误三种情况。每 1.5 秒读取一次，完整且可解析的大纲连续三次一致后进入保存，只比较标签内解析后的大纲，不受其他网页文本或忙碌标记影响。格式错误或无法读取完整虚拟代码文档时，待网页空闲且非空抓取文本稳定后展示具体错误。虚拟代码框可见片段禁止保存。不要求标签与抓取文本整行完全相等，不依赖网页 DOM 自动补全的标签判断生成结束。

生成阶段使用独立的三分钟定时器，不依赖下一次轮询才能触发。读取网页回复最多等待十秒，读取网页状态最多等待五秒；超时或取消会停止本地等待，迟到的返回值不能继续保存，也不会自动重发。错误详情包含执行阶段、读取来源、字符数、容器数和稳定次数，不记录对话正文。保存开始前清除生成定时器，避免已经写入后被标记为生成超时。

渲染层在任务进行时每两秒读取主进程任务状态，事件通知仍即时更新；读取期间收到新事件时丢弃旧快照，防止状态倒退。同步到完成状态后重新读取笔记结果。单个窗口通知失败不影响任务推进或其他窗口接收更新。

第一版直接注入文本，设置明确大小上限，超过上限返回可理解提示，绝不静默截断。文件上传与分段生成在有实测必要时再扩展，避免为不同平台附件行为增加未验证链路。

等待设定总体超时，过程中允许取消。发送结果不明确时不自动重发。用户处理登录后通过主动重试创建新任务。任务完成/取消释放专用窗口；失败时仅在用户选择查看时展示现存网页，下一次重试前清理。

## 6. IPC 与职责

新增契约同时同步 main、preload 实现与声明、renderer 调用。统一 `{ success, data?, error? }` 返回结构。

| 能力 | 主进程职责 | 前端职责 |
| --- | --- | --- |
| 采集来源 | 验证 WebContents 并采集、保存共享快照 | 提供当前源实例，展示来源 |
| 开始/查询/取消任务 | 管理唯一任务、窗口与状态，保存最终导图 | 订阅状态，提供操作 |
| 显示生成网页 | 用户主动操作时显示专用窗口 | 登录/失败状态提供入口 |
| 导图创建/修改/删除 | 串行写文件、大小和冲突检查 | 编辑、防抖保存、提示错误 |
| 在笔记中打开 | 向主窗口发送定位并显示主窗口 | 定位对应会话和导图 |

主进程只广播任务摘要与笔记变更，不广播原始提示词或中间回复。前端通过查询恢复任务状态，以兼容晚订阅、切页和 HMR。

## 7. 笔记页设计

左侧仍按来源会话组织，显示批注与导图数量，加入全部/有批注/有导图筛选，搜索包含导图标题和大纲。中间增加思维导图标签，复用本地编辑器。只有导图没有批注也能查看共享快照，只有快照的记录不能触发空数组访问错误。

点击批注仍定位共享快照原文，不再切换正文到该批注的历史快照。无法定位时提示但保留评论。原网页高亮沿用文本锚点逻辑。导出全部笔记时包含一次共享快照、批注和导图大纲；JSON 导出包含完整结构。

## 8. 开发步骤及影响文件

1. 更新共享类型及 NoteManager：迁移、串行保存、共享快照、多图 CRUD 和导出。

4. 本地编辑器支持文档输入与保存回调，保留现有交互；新增会话导图容器复用于两种窗口和笔记页。
5. 主窗口传当前单对话实例，快捷窗口传当前主实例；处理网页内导航更新来源及跨会话结果归属。
6. 笔记页使用共享快照，增加导图视图、筛选、搜索、定位和导出。
7. 审查 diff 并依次执行 lint、build、dev 实际验证，记录限制。

## 9. 验收与回归

遵循 `npm run lint` → `npm run build` → `npm run dev`。项目没有测试运行器，不新建框架。必要的类型检查区分仓库既有问题与本次问题。

| 场景 | 预期 |
| --- | --- |
| 主窗口/快捷窗口生成 | 默认当前平台，可切换其他平台，原对话不出现生成提示词 |
| 多轮及长对话 | 快照包含用户提问和 AI 回答，符合当前平台实际加载范围 |
| 同源添加多条批注 | 磁盘正文只一份，高亮和评论都保留 |
| 登录/验证码/网络异常 | 不报成功，可主动打开生成网页处理或重试 |
| 缓慢输出或空抓取 | 不保存半段或空大纲，不固定五秒判断完成 |
| 生成时换会话/切页/隐藏 | 正确保存到启动来源，不把结果显示到其他会话 |
| 取消/退出 | 不追加导图，后台资源释放，无自动重发 |
| 编辑、撤销、切图、重启 | 内容保存，撤销不串文档，失败显示并可重试 |
| 两窗口编辑同一图 | 冲突可见，不静默丢掉另一个窗口编辑 |
| 重新生成/删最后批注 | 新图与旧图共存，导图不随批注删除丢失 |
| 旧数据迁移及重复读取 | 批注引用与评论保留，导图迁入一次，可恢复原文件 |
| 笔记导航、搜索和导出 | 目标会话与导图正确定位，导出快照只出现一次 |

无法独立触发真实 AI 网页或系统窗口操作时，明确区分已通过的本地开发验证与待用户执行的实际网页验收，列出最小操作步骤，不把构建成功当作网页功能成功。
