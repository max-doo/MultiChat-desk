本参考合并两份上游资产：anthropics pptx skill 的设计指南（Apache-2.0）与 MiniMax pptx-generator 的设计系统（MIT），并针对中文演示场景做了取舍。流程与雷区以 SKILL.md 为准，本文提供配色、风格、排版的具体配方。

## 设计原则

**不要做无聊的幻灯片。** 白底加一堆项目符号不会给任何人留下印象。为每页从下面的清单里选择设计手法。

动手之前：

- **挑选大胆、贴合内容的配色**：配色应该感觉是为"这个主题"设计的。如果把你的配色换到一份完全不同的演示里照样"能用"，说明选择还不够具体。
- **主次要分明，不要平均主义**：一个颜色占主导（60-70% 视觉权重），1-2 个辅助色，一个锐利的强调色。永远不要让所有颜色权重相同。
- **明暗对比**：标题页+结尾页用深色底、内容页用浅色底（"三明治"结构）。或者全程深色走高端感。
- **坚持一个视觉母题**：选一个标志性元素贯穿始终——圆角图片框、彩色圆圈中的图标。**不要用色条/装饰线当母题**（见避坑清单）。

## 风格配方（圆角与间距体系）

同一个设计可以通过调整圆角（`rectRadius`）和间距呈现四种迥异的视觉风格。按演示调性选一种并贯穿始终：

| 风格 | 圆角范围 | 间距 | 适用 |
|-------|--------------|---------|----------|
| 直角紧凑 | 0 ~ 0.05" | 紧凑 | 数据密集、表格、专业报告 |
| 柔和均衡 | 0.08" ~ 0.12" | 适中 | 企业商务、通用场景 |
| 圆角舒展 | 0.15" ~ 0.25" | 宽松 | 产品介绍、营销、创意展示 |
| 胶囊轻盈 | 0.3" ~ 0.5" | 开阔 | 品牌展示、发布会、高端演示 |

组件映射（`rectRadius` 值）：

| 组件 | 直角 | 柔和 | 圆角 | 胶囊 |
|-----------|-------|------|---------|------|
| 按钮/标签 | 0 | 0.05 | 0.1 | 0.2 |
| 卡片/容器 | 0.03 | 0.1 | 0.2 | 0.3 |
| 图片容器 | 0 | 0.08 | 0.15 | 0.25 |
| 徽章 | 0.02 | 0.05 | 0.08 | 0.15 |

混用规则：

1. **外层容器圆角 ≥ 内层元素圆角**——内层圆角大于外层会产生视觉溢出
2. **信息密度决定间距**：数据展示区用直角或柔和（紧凑），内容浏览区用圆角或胶囊（宽松）
3. **圆角与元素高度匹配**：小元素（< 0.3"）0~0.08"；中元素（0.3~0.6"）0.02~0.12"；大元素（0.6~1.2"）0.03~0.2"；特大（> 1.2"）0.05~0.25"
4. **完美胶囊**：`rectRadius = 元素高度 / 2`

没把握时选**柔和均衡**，圆角不超过 0.12"——中文商务场景的安全选择。

## 版式布局选项

**每页都需要一个视觉元素**——图片、图表、图标或形状。纯文字页记不住。

- 双栏（左文右图或左图右文）
- 图标+文字行（彩色圆圈中的图标，加粗标题，下方描述）
- 2x2 或 2x3 网格（一侧图片，另一侧内容块网格）
- 半幅出血图（整左或整右侧）加内容叠加

数据展示手法：

- 大数字强调块（60-72pt 大数字加下方小标签）
- 对比栏（前后对比、利弊、并排方案）
- 时间线或流程（编号步骤、箭头）

视觉修饰手法：

- 章节标题旁配彩色小圆圈图标
- 关键数据或标语用斜体强调文字

## 字号与间距刻度

### 字号（中文场景，单位 pt）

| 用途 | 字号 | 说明 |
|---------|------|-------|
| 注释/来源 | 10 ~ 12 | 最小可读字号 |
| 正文/描述 | 14 ~ 16 | 标准正文 |
| 副标题 | 18 ~ 22 | 二级标题 |
| 页标题 | 28 ~ 36（中文可到 40） | 页面标题 |
| 大标题 | 44 ~ 60 | 封面/章节页 |
| 数据强调 | 60 ~ 96 | 关键数字展示 |

中文比英文更依赖字号对比拉开层级——页标题不要低于 32pt。

### 间距（单位英寸）

| 用途 | 推荐值 |
|-------|---------------------|
| 图标与文字间距 | 0.08" ~ 0.15" |
| 列表项间距 | 0.15" ~ 0.25" |
| 卡片内边距 | 0.2" ~ 0.4" |
| 元素组间距 | 0.3" ~ 0.5" |
| 页面安全边距 | 0.4" ~ 0.6"（最小 0.5"） |
| 大区块间距 | 0.5" ~ 0.8" |

间距要一致：选定 0.3" 或 0.5" 就全程统一，不要随机混用。

## 字体搭配

### 中文场景（优先遵循）

| 角色 | 推荐 |
|------|------|
| 中文标题+正文（统一） | 微软雅黑（Microsoft YaHei）——最稳妥，全部 Windows 机器自带 |
| 现代感替代 | 等线（DengXian）——Office 2016 及以上才有，老机器缺失 |
| 公文/传统感 | 黑体标题加宋体正文（SimHei 与 SimSun）——正式公文风，但屏幕显示一般 |
| 西文/数字 | 跟随中文字体即可；追求精致可西文 Arial 或 Georgia 与中文雅黑混排 |

主题字体的正确设法见 SKILL.md"中文字体与排版"一节——必须设置 `eastAsiaFontFace`，否则中文不会跟随主题字体。

### 英文/国际化场景字体安全表

- **安全字体**（QA 渲染宽度真实且随 Office 分发）：**Arial, Calibri, Cambria, Times New Roman, Courier New, Bookman Old Style, Century Schoolbook**。正文和任何"放得下与否"要紧的地方用它们。
- **零 QA 风险的个性标题**：安全表内衬线标题（Cambria、Bookman Old Style、Century Schoolbook）配安全表内无衬线正文（Calibri 或 Arial）。
- **QA 不可靠字体**（替换字体宽度不同——溢出检查可能错）：Georgia, Trebuchet MS, Impact, Arial Black, Garamond, Consolas, Palatino Linotype。Calibri Light 的替换随环境而异，同样按不可靠处理。标题/强调可以用但要留余量，别信这些文字的 QA 贴合检查。
- **永远不要用 Aptos 做默认**——Office 2023 后的默认字体在此环境没有度量兼容的替代品，且老 Office 也没有，两端都不可靠。
- 用户指定表外字体时：在用户指定的位置使用，但容器多留约 10% 余量，且不要相信这些元素的 QA 文字贴合检查。

**正文不要加粗**：正文段落、说明文字用常规字重；图注、图例、脚注用常规字重。加粗只留给标题——中文尤其如此，正文整段加粗会显得吵。

## 避坑清单

- **不要重复同一版式**——列、卡片、强调块逐页变化
- **幻灯片标题结尾不要加句号**（中文同样适用）
- **同类页面标题不要漂移**——标题在页顶的内容页，每一页位置、字体、字号、对齐完全一致；不同类型的页（章节页标题居中）可以不同
- **图表标签样式不要页间变化**——坐标轴和数据标签在所有图表中用同一颜色、字体、字号；只在必要时例外（第二坐标轴、高亮系列、深底上的标签）
- **正文不要居中**——段落和列表左对齐；只有标题居中
- **字号对比不要吝啬**——36pt 以上的标题才能和 14-16pt 正文拉开层级
- **不要默认蓝色**——选反映具体主题的颜色
- **不要只装饰一页**——要么全套一致，要么整体从简
- **不要做纯文字页**——加图片、图标、图表或形状；避免"标题加一堆项目符号"
- **别忘了文本框内边距**——线条或形状与文字边缘对齐时，文本框设 `margin: 0` 或按内边距偏移形状
- **不要用低对比元素**——图标和文字都要对背景有强对比；不要浅底浅字、深底深字
- **绝不用标题下的装饰线**——这是 AI 生成幻灯片的标志性特征；用留白或背景色代替
- **绝不加装饰色条或侧边条纹**——包括：横贯页面宽度的页眉页脚色条、沿页面一侧的竖条、卡片或内容块边缘的细强调条、矩形的"单边框"。这些都像 AI 填充物。想让卡片突出，用浅底色、投影或图标——不要边缘条纹
- **不要默认米色/奶油色背景**——未指定背景时用白色（`FFFFFF`）或用户品牌色；避免暖中性色默认值如 `F5F5DC`、`FAF0E6`、`FAEBD7`、`FFF8E1`
- **不要交付溢出文字**——放不下就缩字号、拆页或扩容器，绝不留着被截断或溢出边界的内容。**不要低于字号刻度下限**（正文 14pt、注释 10pt）——到了下限就删字、扩容器或拆页；编辑现有文件时跟随其原有字号
